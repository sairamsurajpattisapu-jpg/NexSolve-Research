# Jury Defense Evidence Matrix
**SIH 2026 Problem Statement 26153: AI based Network Attack Forecasting from Network Traffic Data**

This matrix provides the defense rationale, exact sample counts, verified metrics, limitations, and verbal defense statements for technical questioning by the SIH Evaluation Jury.

| SIH Claim / Requirement | Implementation Component | Empirical Verification Experiment | Dataset & Split Size | Verified Metric / Result | Known Scientific Limitation | Can We Defend This Verbally? |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **1. Temporal State Dynamics Learning** | `world_model.py` (`NumpyLSTM`) | `experiments/transition_evaluation.py`<br>`artifacts/transition_metrics.json` | UNSW-NB15<br>17 test evaluation pairs | World Model: MSE = 38.72, MAE = 1.66<br>Persistence: MSE = 34.79, MAE = 1.03 | Persistence beats World Model on 1-step MAE (1.03 vs 1.66). Error is dominated by `mean_iat` (MSE 1148.61) due to extreme test-set mean shift. | **YES.** "In 60s windows, network states change incrementally, making static persistence strong at T+1. The World Model is designed for multi-horizon dynamic trajectory simulation." |
| **2. Multi-Horizon Recursive Rollout ($T+1 \dots T+5$)** | `forecast_k_steps` recursive rollout | `experiments/transition_evaluation.py`<br>`artifacts/rollout_metrics.json` | UNSW-NB15<br>12-16 evaluation origins | World Model MSE:<br>T+1 (41.10), T+2 (34.63), T+3 (27.45), T+4 (24.70), T+5 (24.40)<br>Persistence MSE degrades to 59.80 at T+5 | Decreasing error curve is partly due to sample truncation (N=16 down to N=12), but on fixed 12 origins, WM consistently beats Persistence for $H \ge 2$. | **YES.** "Autoregressive rollout error remains tightly bounded through T+5, whereas Persistence error grows to 59.80 as traffic diverges from origin." |
| **3. Future Infiltration Forecasting** | Attack risk head in `NumpyLSTM` | `experiments/baseline_comparison.py`<br>`artifacts/baseline_metrics.json` | UNSW-NB15<br>17 test pairs (11 attack, 6 benign) | Recall = **11/11 (100%)**<br>Precision = 0.6471 (11/17)<br>F1 = 0.7857, FPR = 0.4545 | 100% recall is evaluated on 11 attack test windows. With small sample size, 6 false positives occur. | **YES.** "We explicitly disclose the sample count (11/11). The model prioritized zero false negatives on impending attacks over precision." |
| **4. Logistic Regression Baseline** | `experiments/baseline_comparison.py` | Head-to-head comparison under identical 45-feature schema | Identical 17 test pairs | LogReg: F1 = 0.8148, Recall = 11/11 (100%), Precision = 0.6875, ROC-AUC = 0.2121 | LogReg achieves higher F1 (0.8148 vs 0.7857) due to 1 fewer false positive, but has low ROC-AUC due to lack of temporal sequence memory. | **YES.** "We do not hide that LogReg achieves 0.81 F1; however, LogReg cannot forecast multi-step continuous trajectories or roll forward." |
| **5. | **6. | **7.
